Publishing Reference

CSV upload formats, one per tool.

Seven tables power the site. Match the column headers below exactly — Supabase's importer maps by header name, not position — and everything else (badges, gating, page layout) is already wired up.

01

Open your Supabase project → Table Editor

02

Pick the table, click Insert → Import data from CSV

03

Upload your file — headers must match exactly

04

Save. The live page reflects it immediately.

Redraft Weekly Rankings

table: redraft_rankings
Free — everyone

Standard redraft rankings, refreshed weekly. Shown in full to every visitor.

CSV header row
season,week,rank,player_name,position,team,notes
ColumnRequiredNotes
seasonoptionalDefaults to the current year if left blank
weekrequiredNFL week number, e.g. 1–18
rankrequired1 = top ranked
player_namerequiredFull name, e.g. CeeDee Lamb
positionrequiredQB / RB / WR / TE
teamoptional3-letter code, e.g. DAL
notesoptionalShort blurb shown next to the row
seasonweekrankplayer_namepositionteamnotes
202611CeeDee LambWRDALElite floor and ceiling this matchup.
Publishing a new week: just import a CSV with a higher week number — the page always shows whichever season/week is highest. Old weeks stay in the table as history, no need to delete anything.

player_namerequiredFull name
positionrequiredQB / RB / WR / TE

stack_noteoptionalTooltip text on the STACK badge, e.g. which players it pairs with
seasonboard_typeroundpickplayer_namepositionteamis_stackstack_note

Startup vs. rookie: both live in the same table, split by board_type — the live page has a toggle between them. Republishing: this one isn't weekly; a full re-import under a higher season is the way to publish a new version.

Player Season Simulations

Singularity only

Floor / median / ceiling per player from your season-long model. Explorer does not unlock this one.

CSV header row
season,player_name,position,team,floor,median,ceiling,notes
ColumnRequiredNotes
seasonoptionalDefaults to the current year
player_namerequiredFull name
positionrequiredQB / RB / WR / TE
teamoptional3-letter code
floorrequired10th percentile, numeric (e.g. fantasy pts/game)
medianrequired50th percentile — sets the default sort order
ceilingrequired90th percentile, numeric
notesoptionalShort blurb
seasonplayer_namepositionteamfloormedianceiling
2026CeeDee LambWRDAL8.216.428.1
floor / median / ceiling render as a range bar on the live page — keep them in the same unit (points per game works well) so the bars stay comparable across players.
